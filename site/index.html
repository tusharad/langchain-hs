New to Haskell?

Why Haskell is the Ultimate Language for AI Agents

Tired of Python agents crashing at 3 AM due to a missing dictionary key, a silently mutated state variable, or a runtime type mismatch? Haskell solves the hardest problems in agentic engineering:

  • Zero State Hallucinations: Agent workflows are expressed as pure state reducers (StateReducer s). State transitions cannot accidentally mutate or leak memory.
  • Guaranteed JSON Types: LLM structured outputs parse directly into Haskell records via FromJSON. If an LLM hallucinates an invalid field, the type system safely catches it.
  • Lego-Like AST Pipelines: Pipe components together with |>> (sequential), &>& (parallel fan-out), and >>># (fallback resilience) without writing boilerplate.
  • No Category Theory Required: Our canonical Langchain.Prelude provides intuitive functions like invoke, runReActAgent, and emptyStateGraph that feel as natural as Python.
New to AI Frameworks?

Demystifying AI: The 4 Core Mental Models

If you know functional programming or backend architecture but haven't worked with LLM orchestration frameworks, here is the entire agentic paradigm in four simple concepts:

  • 1. Chat Invocation: Send structured messages (systemMessage, userMessage) to an LLM (Ollama, OpenAI, Gemini) and receive a typed assistant response.
  • 2. Structured Output: Force the model to generate strict JSON schemas that deserialize directly into native domain data structures without prompt hacking.
  • 3. Tool Calling: Equip the model with effectful functions (database queries, calculators, file search) that the model chooses and invokes with typed parameters.
  • 4. ReAct & State Graphs: Autonomous "Reasoning + Acting" loops where models iteratively choose tools, observe outputs, and update cyclic state machines until done.

Interactive Multi-Provider Execution

Switch between local inference (Ollama), cloud APIs (OpenAI / OpenRouter), and Google Gemini. Every example includes realistic terminal output.

{-# LANGUAGE OverloadedStrings #-}
module Main where

import Control.Monad.Except (runExceptT)
import qualified Data.Text.IO as T
import Langchain.Prelude
import Langchain.Provider.Ollama

main :: IO ()
main = do
  -- Connect to local Ollama instance (DeepSeek, Llama 3, Gemma, etc.)
  model <- newOllama "llama3.2" defaultConfig
  
  let msg = [userMessage "Explain why Haskell's type system makes AI agents more reliable in 2 sentences."]
  res <- runExceptT $$ invoke model msg Nothing
  case res of
    Left err -> T.putStrLn $$ errorMessage err
    Right m  -> T.putStrLn $$ extractMessageText m

The 4 Pillars of Production AI in Haskell

From guaranteed JSON extraction to autonomous ReAct tool loops, here is how you build real systems.

Pattern 1

Guaranteed JSON Structured Output

Parse LLM output directly into strongly typed Haskell records using FromJSON and ToSchema.

data Developer = Developer
  { name :: Text
  , language :: Text
  , years :: Int
  } deriving (Show, Generic, FromJSON, ToSchema)

runExtraction :: IO ()
runExtraction = do
  m <- newOllama "llama3.2" defaultConfig
  let opts = withStructuredOutput (Proxy @Developer) defaultOllamaConfig
  res <- runLangchainT () $$ invoke m prompt (Just opts)
  print res

Pattern 2

Typed Tool & Function Calling

Equip LLMs with effectful Haskell functions. The model emits structured tool calls that execute safely.

-- Create filesystem search tool
let fsTool = findFilesTool @IO defaultSecurityPolicy
    toolCfg = withTools [fsTool] defaultOllamaConfig

-- LLM chooses and invokes tool
resp <- invoke model prompt (Just toolCfg)
case messageToolCalls resp of
  Just (tCall:_) -> do
    out <- toolExecute fsTool (toolCallArguments tCall)
    print out

Pattern 3

Autonomous ReAct Agent Loop

Dynamic multi-turn reasoning and acting loop that evaluates tool observations until reaching final answers.

main :: IO ()
main = do
  m <- newOllama "qwen2.5:7b" defaultConfig
  let tools = [readFileTool Nothing defaultSecurityPolicy]
      agent = defaultReActAgent m tools
  
  res <- runExceptT $$ runReActAgent agent [userMessage "Check server status in /tmp/status.txt"]
  print res

StateGraph Cyclic Workflows

workflow :: StateGraph WorkflowState IO
workflow = emptyStateGraph workflowReducer
